Lab 03

Creating Data: Digitizing & Georeferencing

Learn the art of creating vector data from raw imagery. Turn a historic paper map into a digital spatial asset.

🎯 Learning Objectives

  • Georeference a scanned paper map or aerial image to align it with the real world.
  • Create empty Vector Datasets (Shapefiles/Feature Classes) with specific attribute fields.
  • Digitize points, lines, and polygons by tracing features.
  • Understand Snapping to ensure topological connectivity.

📂 Scenario: The Historic Campus

The University Archives has provided a scanned map of the campus from 1950. It is just a JPEG image with no coordinates. Your task is to align it to the modern satellite basemap and digitize the footprints of the original buildings to calculate how much the campus has expanded.

Data Package: lab03_digitizing.zip

Contains: campus_1950.jpg (Unreferenced Image)

Download Data
Concept Check: You cannot digitize accurately if your background map is floating in the ocean. You MUST Georeference first!

🛠️ Step-by-Step Instructions

Select your preferred GIS platform to view instructions:

1

Georeferencing

1. Add campus_1950.jpg to the map. It will ask to "Build Pyramids" (Yes).
2. Go to Imagery tab > Georeference.
3. Use the "Fit to Display" tool to bring the image roughly into view.
4. Add Control Points: Click a building corner on the JPEG, then click the same building corner on the Basemap.
5. Add at least 4 points. Click Save to burn in the coordinates.

2

Create Feature Class

1. In the Catalog Pane, right-click your Geodatabase > New > Feature Class.
2. Name: Historic_Buildings. Type: Polygon.
3. Add a Text field called Building_Name.
4. Click Finish.

3

Digitizing & Snapping

1. Go to Edit tab > Create.
2. Enable Snapping (the magnet icon).
3. Select the "Polygon" construction tool.
4. Trace the buildings from the 1950 map. Double-click to finish a shape.
5. Open the Attribute Table and type the names.

1

Georeferencer Plugin

1. Go to Layer > Georeferencer.
2. Open campus_1950.jpg.
3. Click a point on the image, then choose "From Map Canvas" to click the corresponding point on the OpenStreetMap basemap.
4. Add 4+ points.
5. Click the "Play" (Start Georeferencing) button. Choose "Helmert" transformation.

2

New GeoPackage Layer

1. Layer > Create Layer > New GeoPackage Layer.
2. Database: lab03.gpkg. Table: Historic_Buildings.
3. Geometry: Polygon.
4. New Field: Name (Text). Add to Fields list.

3

Toggle Editing

1. Right-click the new layer > Toggle Editing (Pencil icon).
2. Click "Add Polygon Feature".
3. Trace the buildings. Right-click to close a polygon.
4. Enter the Name in the popup form.

1

Web Georeferencing

Standard Web GIS limits image rectification. We will use the custom Web Georeferencer tool.

Tool Link: Launch Web Georeferencer

1. Load Image: Upload your campus_1950.jpg.
2. Set Control Points: Click a point on your image (Left Panel), then find the same location on the satellite map (Right Panel). Repeat for 4 corners.
3. Warp: Click "Georeference Image".
4. Export: Download the result as a GeoTIFF or copy the Tile URL to use in AGOL.

2

Digitizing in Map Viewer

1. Create a "Sketch" layer in ArcGIS Online.
2. Choose the "Polygon" tool.
3. Trace features over the Imagery basemap.
4. Limitation: Sketch layers are not true databases. To create real data, you must publish a "Hosted Feature Layer" first.

✅ Submission & Assessment

To complete this lab, you must submit:

  • Screenshot 1: Your Georeferenced 1950 map overlaid on the modern basemap (set transparency to 50% to show alignment).
  • Screenshot 2: Your digitized polygons with a label showing the "Building_Name".
  • Bonus: Calculate the area of the "Old Main" building in square feet.
