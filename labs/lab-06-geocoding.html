💡 What is Geocoding?

Geocoding is the process of converting a human-readable address (like "3100 Cleburne St, Houston, TX") into geographic coordinates (latitude and longitude) so it can be placed on a map.

Think of it this way: when you type an address into Google Maps or Uber, the app performs geocoding behind the scenes. It takes your text and finds the exact spot on Earth.

Industry Fact: Geocoding is one of the most expensive operations in commercial GIS. Services like Esri, Google, and Mapbox charge per address. A company geocoding millions of customer addresses could spend thousands of dollars. Your TSU ArcGIS account gives you this capability for free!

2

Sign In and Open Map Viewer

  1. Go to arcgis.com and sign in with your TSU account (see Sign-In instructions above).
  2. Click "Map" in the top navigation bar to open the Map Viewer.
  3. You should see a blank world map with a dark toolbar on the left.
3

Upload and Geocode Your CSV

  1. On the left toolbar, click the "Add" button (the + icon).
  2. Click "Add layer from file".
  3. Drag your CSV file into the upload area, or click "Your device" to browse for it.
  4. ArcGIS will detect the address columns and ask how to locate the features. Make sure "Addresses" is selected (not "Coordinates").
  5. Click "Next", then "Create layer".
  6. Wait a few seconds. Your points will appear on the map!
Common Mistake #2: If your points do not appear, check that your CSV column headers are exactly Name, Address, City, State, Zip with no extra spaces. ArcGIS uses these names to match address fields.
4

Customize Your Map

  1. Labels: Click your layer name in the Layers panel on the left. Click the "Labels" icon (tag icon). Turn labels ON and set the label field to Name.
  2. Basemap: Click the "Basemap" button (left toolbar). Try "Streets" or "Navigation" for a clean look.
  3. Symbology: Click your layer, then click the "Styles" icon (paintbrush). Choose a bold, visible symbol color.
  4. Zoom: Zoom in so all your points are visible and fill most of the screen.
5

Print and Export as PDF

  1. On the left toolbar, click the "Print" button (printer icon).
  2. Enter a descriptive title for your map (e.g., "Houston Landmarks Geocoding Lab").
  3. Layout: Choose "Letter ANSI A Landscape".
  4. Format: PDF.
  5. Click "Export". Wait a few seconds, then click the result to download your PDF.

The PDF will automatically include a north arrow, scale bar, and legend. That is your T.O.L.S. covered!

1

Prepare Your CSV File

Create a CSV file with columns Name, Address, City, State, Zip (or download the ready-made CSV). Save it somewhere easy to find, like your Desktop.

2

Add the CSV to Your Project

  1. Open ArcGIS Pro and create a new Map project (or open an existing one).
  2. In the Catalog Pane (right side), navigate to where you saved your CSV.
  3. Drag the CSV file into the Contents Pane (left side). It will appear as a table (no points yet).
3

Geocode the Addresses

  1. Right-click the CSV table in the Contents Pane → select "Geocode Table".
  2. For Input Locator, choose the ArcGIS World Geocoding Service.
  3. Map your fields: Address → Address, City → City, State → State, Zip → ZIP.
  4. Click Run. The geocoded points will appear on your map.
Alternative Method: Go to Analysis → Tools. Search for "Geocode Addresses". Set the input table to your CSV and the locator to the ArcGIS World Geocoding Service. This is the same thing, just accessed from the toolbox.
4

Label and Style Your Points

  1. Right-click your geocoded layer → Label Features.
  2. In the Labeling Tab, set the label field to Name.
  3. Double-click a point to open Symbology. Choose a bold color and size 12+ for visibility.
  4. Change the Basemap (Map Tab → Basemap) to "Streets" or "Topographic".
5

Create a Layout and Export

  1. Go to Insert → New Layout. Select "Letter (8.5 x 11) Landscape".
  2. Go to Insert → Map Frame. Draw a rectangle to place your map.
  3. Add T.O.L.S. elements from the Insert Tab:
    • Text: Your map title
    • North Arrow: For orientation
    • Scale Bar: For distance
    • Legend: For symbol explanation
  4. Go to Share → Export Layout. Format: PDF. DPI: 300. Save it.
No Account Required! QGIS is free and open-source. If you are having trouble with ArcGIS login, this is your best backup option.
1

Install the MMQGIS Plugin

  1. Open QGIS Desktop.
  2. Go to Plugins → Manage and Install Plugins.
  3. In the search bar, type MMQGIS.
  4. Click Install Plugin. You will see a new MMQGIS menu appear at the top.
What is MMQGIS? It is a popular plugin that adds geocoding (and many other features) to QGIS. It uses the free OpenStreetMap/Nominatim geocoding service, so you do not need any API keys or accounts.
2

Prepare Your CSV File

Create a CSV or download the ready-made CSV. Same rules apply: columns must be Name, Address, City, State, Zip.

3

Geocode the CSV

  1. Go to MMQGIS → Geocode → Geocode CSV with Web Service.
  2. Select your CSV file as the input.
  3. Web Service: Choose OpenStreetMap / Nominatim.
  4. Map the columns:
    • Address → Address
    • City → City
    • State → State
    • Country → (leave blank or type "US")
  5. Click Run. After a moment, points will appear on your canvas!
Common Issue: Nominatim has a rate limit (1 request per second). If you have many addresses, the process may take a minute. Be patient and do not close QGIS during processing.
4

Add a Basemap and Style

  1. Add a basemap: Go to Web → QuickMapServices → OSM → OSM Standard.
    (If you do not have QuickMapServices, install it: Plugins → Manage Plugins → search "QuickMapServices")
  2. Make sure your geocoded points layer is above the basemap in the Layers panel (drag to reorder).
  3. Right-click the points layer → Properties → Labels. Set to "Single Labels" and choose Name as the label field.
  4. Under Symbology, choose a bold marker color and increase the size.
5

Create Print Layout and Export

  1. Go to Project → New Print Layout. Name it "Geocoding Lab".
  2. Use Add Map to draw your map frame on the page.
  3. Add T.O.L.S. elements using the toolbar:
    • Add Label: For your title
    • Add North Arrow: For orientation
    • Add Scale Bar: For distance
    • Add Legend: For symbol explanation
  4. Click Layout → Export as PDF. Save to your computer.

⚠️ Common Mistakes (Read Before Submitting!)

#1: Saving as .xlsx instead of .csv

ArcGIS Online and QGIS expect CSV files. If you save from Excel, make sure to change the format to "CSV (Comma delimited)" in the Save As dialog.

#2: Missing or misspelled column headers

Your CSV must have columns named exactly Name, Address, City, State, Zip. Extra spaces or different names (like "Street" or "Zipcode") will cause geocoding to fail.

#3: Submitting a screenshot instead of a PDF

Use the Print/Export tool to generate a proper PDF with T.O.L.S. elements. Phone screenshots and Windows Snipping Tool captures will not have a title, legend, or scale bar.

#4: Fewer than 5 geocoded points

You need at least 5 addresses on the map. The ready-made CSV has 7; just use that if you are unsure.

#5: No labels on the map points

Points must be identifiable. Turn on labels (using the Name field) so the reader knows which point is TSU, which is NRG Stadium, etc.
