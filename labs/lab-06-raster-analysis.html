Lab 06

Raster Analysis: Suitability Modeling

Where is the "Best" place? Use Weighted Overlay and Map Algebra to find optimal locations.

🎯 Learning Objectives

  • Derive new surfaces from a DEM (Slope, Aspect).
  • Calculate Euclidean Distance from vector features.
  • Reclassify different data types into a common scale (1-10).
  • Perform a Weighted Overlay to combine factors into a final suitability map.

📂 Scenario: The New Fire Station

The city needs to build a new fire station in the mountains. You have been tasked with finding the best site based on three criteria:

Site Criteria:
  1. Slope: Must be flat (flatter is better).
  2. Road Access: Must be close to existing roads (closer is better).
  3. Land Cover: Must not be on water or protected forest.
Data Package: lab06_suitability.zip

Contains: DEM.tif, Roads.shp, LandUse.tif

🛠️ Step-by-Step Instructions

Select your preferred GIS platform to view instructions:

1

Derive Surfaces

1. Open Geoprocessing > Slope.
2. Input: DEM.tif.
3. Output: Slope_Map.
4. Run. The output shows steepness in degrees.

2

Euclidean Distance

1. Search for Euclidean Distance (Spatial Analyst).
2. Input: Roads.shp.
3. Output: Distance_Roads.
4. Run. The output is a raster where every pixel value is the distance to the nearest road.

3

Reclassify

We need to compare "Degrees of Slope" (0-90) with "Meters of Distance" (0-5000). To do this, we reclassify both to a 1-10 scale.
1. Reclassify tool.
2. Input: Slope_Map.
3. Remap: 0-5 deg = 10 (Best), >30 deg = 1 (Worst).
4. Repeat for Distance_Roads (0-100m = 10, >1000m = 1).

4

Weighted Overlay

1. Search for Weighted Overlay.
2. Add your Reclassified Slope and Reclassified Distance layers.
3. Assign weights (e.g., Slope 50%, Roads 50%).
4. Run. The result is your final Suitability Map.

1

Slope

1. Raster > Analysis > Slope.
2. Input: DEM.tif.
3. Run.

2

Proximity (Raster Distance)

1. Raster > Analysis > Proximity (Raster Distance).
2. Note: You may need to rasterize vector roads first.
3. Run to get distance raster.

3

Raster Calculator (Normalization)

QGIS does not have a simple "Weighted Overlay" wizard. We use math.
1. Normalize Slope to 0-1: 1 - ("Slope" / MaxSlope).
2. Normalize Distance to 0-1: 1 - ("Distance" / MaxDist).

4

Final Map Algebra

1. Raster > Raster Calculator.
2. Formula: ("NormSlope" * 0.5) + ("NormDist" * 0.5).
3. The result is a 0-1 suitability score.

1

Suitability Modeler (AGOL)

1. ArcGIS Online Map Viewer has a dedicated Sketch Suitability widget in some apps, or use the Analysis > Summarize Data tools.
2. Note: Full raster processing usually requires Image Server extensions. Integrating pre-processed layers is easier.

2

Enrich Layer

Alternatively, use vector grid cells.
1. Create a Hexbin grid.
2. Enrich Layer with Slope and Distance attributes.
3. Use "Smart Mapping" styles to visualize the average score.

✅ Submission & Assessment

To complete this lab, you must submit:

  • Suitability Map: Color-coded from Red (Bad) to Green (Good).
  • Site Recommendation: Identify one specific area (lat/long) that has a score of 9 or 10.
  • Written Justification: Why did you choose the weights you did? (e.g. Is slope more important than road access?)
